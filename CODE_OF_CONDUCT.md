# Code of Conduct

Be respectful, technically constructive and focused on the work.

This project welcomes bug reports, test evidence, documentation improvements and code contributions from people with different levels of Proxmox and shell experience. Critique code and assumptions rather than people.

Unacceptable behavior includes harassment, threats, deliberate disruption, publishing another person's private information, or using project spaces to target contributors.

Maintainers may edit, hide or remove contributions that materially violate these expectations and may restrict participation when necessary to keep the project usable and safe.
