## Evidence limitation and v3.5.2 correction

The v3.5.1 result archive itself did not contain project version, test-suite version, host/tool versions, a fixture manifest, or a hash manifest binding the run to the exact tested source tree. The source/result association above therefore depends on the two artifacts being supplied together.

v3.5.2 corrects that evidence-quality limitation. New result directories record `environment.txt`, `versions.txt`, `project-sha256.txt`, `fixture-manifest.txt` and `summary.txt`, and successful static-run evidence is retained.

Because v3.5.2 changes command preflight/inspection behavior and expands the real integration definition, the clean v3.5.1 run is a predecessor baseline rather than proof that v3.5.2 has passed real-host acceptance.
