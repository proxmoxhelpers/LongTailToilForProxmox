# `import-vm.sh`

[Back to helper list](../README.md) · [View script](../import-vm.sh) · [Raw usage](./import-vm.sh.usage)

## Purpose

Restores a LongTail single-file VM archive using the restore program carried inside that archive after validating archive membership and checksums. Exact same-identity restore verifies persistent configuration and guest-visible content while intentionally allowing Proxmox to regenerate QEMU `vmgenid`; restored guests remain stopped unless `--start` is explicitly requested.

## Usage and live help

The built-in help is available without performing the operation:

```sh
./import-vm.sh --help
```

```text
import-vm.sh 3.7.1 (project 3.7.1)

USAGE
  import-vm.sh <archive.ltvm> [--vmid NEWID] [--storage STORAGE] [--start]
               [--no-content-verify] [dryrun|--preflight]

DESCRIPTION
  Restores a LongTail single-file VM archive using the restore program carried
  inside that archive. The archive is checksum-validated before restoration.

EXACT MODE
  With no VMID/storage override, restore requires the original storage IDs,
  restores the original VMID/config/firewall, and by default recomputes every
  archived QEMU disk's full guest-visible SHA-256. QEMU vmgenid is expected to
  be regenerated by Proxmox and is excluded from persistent-config equality;
  all other canonical persistent config must match. Config/content mismatch
  exits 4 and leaves the restored guest stopped for inspection.

RELOCATED MODE
  --vmid and/or --storage are supported convenience overrides, but necessarily
  change identity/storage topology and therefore are not called exact restore.

STATE
  Restored guests remain stopped unless --start is explicitly supplied.

TRUST
  Restore only .ltvm files from a trusted source. Embedded SHA-256 checks detect
  corruption/tampering relative to the archive's own manifest; they are not a
  digital signature and do not authenticate who created the archive.

COMMON OPTIONS

  dryrun, --dryrun,
  --plan                  Enable dry-run/plan mode.
  --preflight             Run the same non-mutating preflight/plan path.
  --no-color              Disable ANSI colour output.
  --quiet                 Reduce non-essential LongTail output where supported.

  Common options may appear anywhere on the command line.
```

## Safety and behavior

- `--help` and `--version` are handled before privilege/environment gates.
- `dryrun`, `--dryrun`, `--plan`, and `--preflight` use the non-mutating plan path; read-only helpers remain read-only.
- `--no-color` disables ANSI output and `--quiet` reduces non-essential LongTail output where supported.
- Ambiguous guest, slot, storage, or LVM identities are refused rather than guessed.
- For mutating helpers, preflight is completed before the first mutation and postconditions are verified after the operation.
- Integration safety/variant coverage: Corrupt/unsafe archive, identity collision, or transfer/restore preflight refusal without guest/storage mutation.
