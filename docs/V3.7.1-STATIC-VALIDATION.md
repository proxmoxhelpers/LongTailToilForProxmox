## Corrective regression contracts

In addition to the existing 74 v3.7.0 contracts, v3.7.1 adds four focused static cases:

1. `copy-vm-disk-options.sh` must verify exact backing identity while treating Proxmox option-field order as semantically irrelevant.
2. `clone-vm-storage-only.sh` must stage source block devices through a regular raw file, must not pass the source LV path directly to `qm importdisk`, must verify staged/imported bytes, and must retain source-activation/staging cleanup.
3. Exact archive restore must exclude Proxmox-regenerated QEMU `vmgenid` from canonical config equality while requiring a regenerated value, and the archive integration test must validate checksums from the extraction root.
4. `send-vm-export-and-restore.sh` dry-run must return before remote preflight/SSH, while explicit remote preflight must use `StrictHostKeyChecking=yes`.

The broader static group continues to validate all 81 commands for POSIX syntax, standalone packaging, lifecycle/elevation, documentation/function comments, help aliases, incomplete-argument usage, parser/help agreement, exact `.usage`/Markdown-help synchronization, dry-run immutability contracts, UUID/physical-identity safety, mount ownership, archive membership validation, rollback and result provenance.
