The accepted real-host predecessor remains **v3.5.1 / suite v2.9.1**, whose supplied 2026-08-17 run passed all 50 static and 88 real integration cases with zero skips, failures or anomalies. See [`V3.5.1-REAL-INTEGRATION-RESULTS.md`](V3.5.1-REAL-INTEGRATION-RESULTS.md).

v3.5.2 expands the real integration definition to **92 cases**. The four additions prove:

1. non-SCSI explicit import slots are refused before `qm importdisk`;
2. custom/unmanaged LVM names remain untouched by managed-name repair;
3. copy-overwrite restores exact disposable state after a test-injected failure after archive/final rename but before attachment;
4. snapshot-overwrite provides the same rollback guarantee.

The failure injection is performed only on temporary test-owned copies of the standalone helpers. Production scripts expose no test failure hook.

Those cases require a disposable real Proxmox/LVM environment and were not executed during this static validation. v3.5.2 therefore remains **release-candidate / statically validated** until its 92-case real-host suite passes with zero protected-state anomalies.
