## New-helper simulation

A synthetic Proxmox/LVM command environment exercised the two new helpers without a real Proxmox host.

`list-all-vm-lvm.sh` correctly:

```text
grouped four referenced LVs beneath VM 100
placed an unrelated host LV under Remaining LVM volumes
```

`move-disk-to-vm.sh` correctly completed simulated real mutations for:

```text
full LV path -> destination VM, default hot mode
source VM + disk number -> destination VM, pause mode
source VM + disk number -> destination VM, stop mode
source VM + disk number -> destination VM, restart mode
```

The synthetic source VM state remained running after hot mode, returned to running after pause, remained stopped after stop, and returned to running after restart.

## Validation boundary

The v3.0.1 baseline already completed real-system integration successfully for the original 36 helpers. The two v3.1.0 additions and the expanded 38-command package should be promoted only after:

```sh
./tests/run-all-tests.sh --run --verbose
```

finishes with every group/case green and zero protected-state anomalies.
