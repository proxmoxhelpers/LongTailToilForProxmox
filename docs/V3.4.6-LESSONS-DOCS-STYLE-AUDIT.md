# v3.4.6 — Lessons, Usage, Testing, and Style Audit

Date: 2026-08-17

v3.4.6 is a documentation and engineering-practice release built on the v3.4.5 tree. It intentionally does not change the storage transaction semantics being exercised by the v3.4.4/v3.4.5 real-host integration run.

## Project lessons learned

A new project-wide document records the concrete Proxmox, LVM and POSIX-shell pitfalls discovered during development:

[`PROXMOX-SHELL-SCRIPTING-LESSONS-LEARNED.md`](PROXMOX-SHELL-SCRIPTING-LESSONS-LEARNED.md)

Topics include:

- Proxmox config deletion that can also free backing storage;
- UUID identity across LVM renames;
- rollback primitives that accidentally become destructive;
- `set -e` / `cmd && die` control-flow traps;
- cancellation exit-status contracts;
- LVM metadata versus block-device probing;
- `vm-*` and `base-*` managed-volume families;
- numeric disk-selector ambiguity;
- cross-bus option compatibility;
- paused SCSI controller topology;
- thin versus regular sparse-copy semantics;
- targeted LVM warning filtering;
- target-host utility option compatibility;
- LXC fixture validity and storage content classes;
- dry-run/protected-state evidence;
- layered fail-closed cleanup;
- logical qcow2 content verification;
- help/usage as a public API.

## Per-helper usage snapshots

For each of the 42 public helpers, v3.4.6 ships:

```text
docs/<script-without-.sh>.md
docs/<script>.sh.usage
```

For example:

```text
docs/change-vmid-of-vm.md
docs/change-vmid-of-vm.sh.usage
```

The `.usage` file is not manually summarized. It is the exact current output of:

```sh
./change-vmid-of-vm.sh --help
```

Static tests compare every usage file byte-for-byte with live help output.

## Validation boundary

v3.4.6 changes documentation, version metadata and static documentation contracts only. It does not claim a new real-host integration result beyond whatever is established by the ongoing v3.4.4/v3.4.5 behavior run.

The real integration definition remains 86 cases.
