# v3.3.0 Static Validation

Date: 2026-08-17

Version 3.3.0 extends all four create-disk helpers with source device-slot selectors, destination device/bus selectors, and the optional `boot` keyword.

Local validation covers:

```text
Project commands                 : 40
Standalone top-level helpers     : 40/40
POSIX /bin/sh syntax             : all project/test shell files
Create-helper CLI contract       : source-slot + dest-slot|dest-bus + boot
README command coverage          : 40/40
Test-matrix command coverage     : 40/40
Plan-only test-group launchers   : all groups
```

The static suite includes a dedicated regression requiring all four create helpers to expose:

```text
source-slot
dest-slot|dest-bus
first_free_bus_slot()
set_destination_boot_first()
boot
```

The intended device ranges are:

```text
ide0..ide3
sata0..sata5
scsi0..scsi30
virtio0..virtio15
```

The real `50-copy-snapshot.sh` integration group has been expanded to exercise:

- source selection by exact QEMU slot;
- exact destination-slot selection;
- bare-bus first-free selection;
- `boot` promotion on add helpers;
- `boot` promotion on overwrite helpers;
- existing overwrite/archive/delete and empty-target behavior.

This document does **not** claim real Proxmox acceptance for the v3.3.0 changes. Before promoting v3.3.0 to the integration-validated baseline, run:

```sh
./tests/groups/50-copy-snapshot.sh --run --verbose
```

and then:

```sh
./tests/run-all-tests.sh --run --verbose
```
