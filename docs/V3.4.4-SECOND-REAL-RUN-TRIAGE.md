## Remaining findings

### Template/base source size

Three create-helper template/base cases failed with:

```text
ERROR: Could not determine source LV size.
```

The helpers were asking `blockdev --getsize64` for size even though the source had already been proven to be an LVM LV. Template/base LVs can have activation/read-only characteristics that make block-device probing less reliable than LVM metadata.

v3.4.4 uses:

```sh
lvs --noheadings --units b --nosuffix -o lv_size "$SOURCE_PATH"
```

in all four create helpers.

This is the authoritative metadata source and does not require the LV to behave like an ordinary active block device merely to determine its configured size.

### Pause mode and SCSI controller removal

The remaining `move-disk-to-vm.sh` pause case and two overwrite pause cases failed on real Proxmox after:

```text
qm suspend <vmid>
qm set <vmid> --delete scsi0
```

with errors such as:

```text
hotplug problem - error on hot-unplugging device 'scsihw0'
```

The same disk hot-unplug succeeds while the guest is running. The failure occurs when the requested disk is backed by a per-disk `virtio-scsi-single` controller or is the last disk on a shared SCSI controller, so Proxmox attempts to remove the controller while the VM is suspended.

v3.4.4 does not try to bypass Proxmox with unsafe direct runtime edits. Instead it preflight-refuses that topology **before mutation**.

Positive pause tests now use:

```text
scsihw: virtio-scsi-pci
scsi0: disk being moved/replaced
scsi1: disposable keeper disk
```

so the disk can be hot-unplugged without requiring controller removal.

A new negative case verifies the unsafe sole/per-disk SCSI topology fails with exact state unchanged.

### LXC network fixture

The network group created an LXC rootfs on a disposable LVM-thin storage whose content declaration was only:

```text
content images
```

The fixture therefore was not a fully valid `rootdir` consumer for `pct`.

v3.4.4 test storages advertise:

```text
content images,rootdir
```

and the network fixture validates both:

```sh
pct config "$NET_CT"
pct set "$NET_CT" --net0 ...
```

before the public helper cases begin.
