Date: 2026-08-17

Version 3.4.0 expands the project to 42 standalone helpers with two read-only inspection commands:

```text
verify-vm-disk-numbering.sh
list-all-vm-lvm-filesystems.sh
```

Local acceptance checks require:

```text
Project commands                      : 42
Standalone top-level helpers          : 42/42
POSIX /bin/sh syntax                  : all project/test shell files
README wget+chmod coverage            : 42/42
Test-matrix command coverage          : 42/42
Plan-only test-group launchers        : all groups
```

The static suite additionally verifies that the numbering helper exposes VMID-mismatch and non-zero-start diagnostics and that the filesystem helper exposes separate `TABLE_HINT` / `CONTENT_FORMAT` columns, uses `sfdisk -d` + offset `blkid -p` probing, and contains no command-position `mount` or `kpartx` operation.

Real-system validation still requires:

```sh
./tests/groups/10-inspection.sh --run --verbose
```

followed by:

```sh
./tests/run-all-tests.sh --run --verbose
```

Do not promote v3.4.0 to the integration-validated baseline until those runs are clean with zero anomalies.
