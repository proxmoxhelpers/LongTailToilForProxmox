## Regression addressed

The first Proxmox v3.0.0 run exposed normal negative probes written in the form:

```sh
probe && die "unexpected state"
```

When such an AND-list was the last command of a function, the expected false result of `probe` became the function's return status. With `set -e`, the command then terminated even though the state was valid.

v3.0.1 removes `&& die` from project/library shell source and adds a static regression that rejects its reintroduction.

Observed failures corrected by this change:

```text
rename-lvm.sh
unmount-vm-drives.sh
renumber-vm-disks.sh
recover-vm-from-volumes.sh
```

The mount-wrapper failures in v3.0.0 were cleanup cascades from `unmount-vm-drives.sh`.

`set-vm-boot-disk.sh` was additionally hardened against a related normal-false return from its boot-order loop.
